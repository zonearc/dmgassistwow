# DMGAssist — rotation helper for Midnight and WoW Forever

DMGAssist shows the next three spells to press, in priority order, from SimulationCraft's priority lists
(Midnight) and WoWSims (WoW Forever). Interrupts and defensives slot in front when they matter; major
cooldowns are part of the rotation (or switched off entirely). A flash tells you the moment to press.

**Early days: please report anything that looks wrong.** We read every report and work through them nightly.

## Reporting a problem
1. Install **DMGAssist_Watchdog** next to DMGAssist (it records what DMGAssist saw and decided).
2. After the problem, type `/dmgw` in game and press **Ctrl+C**.
3. Open https://github.com/zonearc/dmgassistwow/issues → **New issue** → **Bug report**, describe what
   happened, and paste the report.

You'll get a reply there, usually with a fix in the next nightly build to try.

Ideas are welcome too: **New issue → Feature request**.

## Status at a glance
Settings → AddOns → DMGAssist → **Status** shows the version, the spec and rotation detected, the target mode,
boss mods found, keybinds read, and links to report problems.
